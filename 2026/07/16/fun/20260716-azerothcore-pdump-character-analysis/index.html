AzerothCore pdump 文件分析

发表于 2026-07-16

pdump 是 AzerothCore 用来把单个角色完整导出 / 导入的命令（控制台或游戏内 .character pdump write|load|copy）。导出来的文件是一条条 INSERT，把这个角色相关的表都串起来。本文以真实样本 pdump_20260715.txt为切片，对照 PlayerDump.cpp 与 db_characters 建表，把 18 张实际落盘的表逐个拆开：表职能、字段类型与含义、样本数据、表间引用，以及交叉读表后还原出的角色画像。

0. 样本概况

0.3 为什么不能直接灌库

必须通过 pdump load 回放。PlayerDump.cpp 导入时会重写角色 GUID、物品 GUID、邮件 ID、宠物 ID、装备方案 ID，并级联修正引用；直接 mysql < dump.txt 会撞主键或留下悬空引用。

0.4 pdump 导出范围与命令

DumpTables[] 登记的表比本样本多，空表不写 INSERT。本样本无宠物、装备方案、法术 CD、邮件附件。

20. 实操：怎么自己拆 pdump

  1. 统计表行数：提取每条 INSERT INTO 的表名后计数
  2. 按表过滤主表 / 天赋 / 物品
  3. 时间戳：date -r 1784122746（macOS）或 date -d @1784122746（Linux）
  4. 铜币：g=money//10000, s=money%10000//100, c=money%100 → 2096484 = 209g 64s 84c

推荐 Python 解析：

  1. 正则抓 INSERT INTO table (cols) VALUES (vals)
  2. 手写抗引号/换行的值解析器
  3. item_instance 建字典，扫 character_inventory 还原栏位
  4. item_template / DBC 翻译名字

注意：不要直接灌库；大文本字段边界要小心；enchantments 36 token 按 3 一组；任务 status 勿记反。

22. 小结

pdump 表面上是一堆 INSERT，实际是一张以 characters.guid 为根的对象图：

  • 进度：成就、任务、声望、探索、飞行点
  • 能力：法术、天赋、技能、雕文、动作条
  • 资产：钱、物品实体、容器嵌套、邮件
  • 客户端：CVar 与聊天布局
  • 现场：光环、位置、炉石、休息值

把「大法师」这份 29 级样本走通后，再拆其它号通常只差：有无宠物/邮件附件/装备方案、专业与任务段、物品规模、是否双天赋。理解这 18 张表后，角色迁移、坏号修复、刷物品排查都会从「猜字段」变成「按图索骥」。

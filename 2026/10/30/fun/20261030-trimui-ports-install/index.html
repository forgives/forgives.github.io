吹米 Trimui 掌机 adb 装机实战：仙剑1 与 Undertale

发表于 2026-10-30

手上有台吹米（Trimui）掌机，之前一直只玩它 TF 卡里预装的模拟器 ROM。这次想给它装两个”移植游戏”：《仙剑奇侠传1》和《Undertale（传说之下）》。整个过程踩了不少坑，好在每个都用 adb 实测验证到了”游戏真的跑起来”才算数，整理成这篇笔记。

先交代设备底细，后面的坑都和它有关。

1. 设备：不是安卓，是 TinaLinux

adb 连上之后先看系统：

  • TinaLinux（全智 A133P 平台，4× Cortex-A53），不是 Android，但自带 adbd 所以 adb 照常能用；
  • model 显示 __B、product 是乱码，这是吹米固件的老毛病，不影响使用；
  • 存储就一个 TF 卡，挂载在 /mnt/SDCARD（57.5G）：

卡里是标准吹米目录：Roms（约 2500 个模拟器 ROM，GBA/MAME/PS 等 30 多个平台）、Ports、RetroArch、Emus 等。

Ports 是什么

Ports（移植游戏）和 Roms（模拟器）是两条完全不同的路线：

Roms + Emus（模拟） Ports（移植）
原理 模拟器伪装成 FC/GBA 主机跑卡带 游戏程序重新编译成 ARM Linux 原生代码直接跑
开销 大 小，所以这台入门机也能跑 DOOM 级别
代表 模拟器 ROM 仙剑（sdlpal）、Undertale（gmloader）、小丑牌、星露谷

Ports 目录名的约定来自社区工具 PortMaster（这台机器预装了 v6.55）：每个游戏一个目录，放一个 config.json 描述菜单项、一个 launch.sh 启动脚本。原厂 UI 开机扫描这个目录生成游戏列表。机器上已经装好的小丑牌就是这个结构，照着抄就行。

2. 仙剑1（sdlpal）：三个坑

sdlpal 是仙剑 95 版的开源重制引擎，社区有打包好的 PortMaster 移植包：主程序 + 仙剑原版 .mkf 数据文件 + 配置，共 42 个文件 253MB。下载的包先做两件事：确认二进制是 aarch64（file 命令看，三个可执行文件都是 ARM aarch64 ✅）、确认 config.json 格式和机器上已有的小丑牌一致（✅，label 已经写好”仙剑奇侠传”）。然后开始推。

3. Undertale（gmloader）：壳和数据是分开的

Undertale 是 GameMaker 引擎游戏，移植思路完全不同：社区工具 gmloader 直接运行安卓版的 GameMaker 运行时（libyoyo.so）+ 游戏数据（game.droid）。因为 Undertale 是付费游戏，移植包按规矩不带数据，得自己备。

打了两次包：第一次进了游戏，但没音乐

第一次只打包了 game.droid + splash + libyoyo 三个文件（82MB），推上去一跑——进程稳定存活 30 秒，日志里 Entering main loop、开场房间 BeginToEnd 加载完成、手柄绑定成功，游戏真的进去了。但日志末尾露馅：

原来安卓版 Undertale 的音乐不在 game.droid 数据包里，而是 APK assets 下的独立 ogg 文件，引擎按文件名现取现放。只打数据文件等于无声版。

解法：把 APK 的 全部 assets（217 个文件，含全部音乐）+ libyoyo 一起打进去，最终 176MB。重新推送后再跑 30 秒：

  • 进程存活 ✅
  • 主循环进入、开场加载 ✅
  • 音频错误 0 条 ✅

到掌机上刷新 Ports 列表，”传说之下”出现，直接能玩。日志里剩余的 undertale.ini / config.ini 找不到是首次运行的正常现象，存档后自动生成。

5. 通用流程总结

给这台机器装任何移植游戏，照这个顺序走基本不踩坑：

  1. 验包：file 确认二进制 aarch64；config.json 对照已装端口格式；
  2. 推送：ASCII 路径下推，核对文件数和目录名（vfat 免 chmod）；
  3. 补库：依赖检查（/lib/ld-linux-aarch64.so.1 --list），缺 SDL2 就从 /rom/usr/trimui/lib/ 拷；
  4. 审启动脚本：环境变量在所有进程启动之前设好；gmloader 类用极简模板；
  5. 冒烟测试：后台跑 15~30 秒，pidof 看进程、读日志找成功标志（gmloader 是 Entering main loop，音频类移植重点盯 could not find audio），然后 kill 干净；
  6. UI 刷新：Ports 列表刷新即见，无需重启。

两台”游戏”现在的状态：仙剑 95 版直接进；《传说之下》测试时已经跑进开场，存档在 /mnt/SDCARD/Ports/undertale/save/。下一个想装的是暗黑1（DevilutionX），不过那又是另一个需要自备数据文件的故事了。
